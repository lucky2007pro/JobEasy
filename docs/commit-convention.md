# Commit Xabar Standarti

## Tavsiya etilgan format
`type(scope): qisqa aniq xabar`

## Type'lar
- feat: yangi imkoniyat
- fix: xatoni tuzatish
- refactor: xulqni o'zgartirmasdan kodni yaxshilash
- test: testlar
- docs: hujjatlar
- ci: pipeline yoki infra

## Misollar
- `feat(cart): add quick add-to-cart endpoint`
- `fix(auth): correct session check in login filter`
- `test(order): add integration scenario for checkout flow`
- `ci(build): run cmake build and ctest on pull requests`
