# 05. UI/UX Test va Feedback Rejasi

## UI/UX Prinsiplar
- Oddiy navigatsiya (3 klik ichida asosiy vazifa).
- Kontrast va matn o'qilishi (WCAG 2.1 AA).
- Mobil-first layout.

## Usability Test Ssenariylari
1. Mahsulot qidirish va product detail ochish.
2. Savatchaga qo'shish va buyurtma yakunlash.
3. Profilni yangilash.
4. Wishlist bilan ishlash.

## O'lchovlar
- Task completion rate >= 90%.
- Time on task.
- Xatolar soni.
- Foydalanuvchi qoniqish balli (CSAT).

## Feedback Yig'ish
- In-app qisqa so'rov.
- Telegram/Email support feedback.
- Release'dan keyin 1-haftalik monitoring.
