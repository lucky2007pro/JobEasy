# 03. MVP Reja

## MVP Scope (eng muhim qulayliklar)
- Avtomatlashtirilgan:
  - Login/session oqimi.
  - Cart -> Checkout -> Order oqimi.
- Tezkor kirish:
  - Search endpoint.
  - Kategoriya va asosiy CTA tugmalar.
- Shaxsiylashtirish:
  - Profile ko'rish/yangilash.
  - Wishlist boshqaruvi.
- Intuitiv UI:
  - Bosh sahifa, mahsulot, savatcha, buyurtma, profil sahifalari.
- Moslashuvchanlik:
  - Mobil va desktopda bir xil asosiy user flow.

## MVP Backlog (prioritet)
1. Auth va sessionni barqaror qilish.
2. Product listing + detail.
3. Cart CRUD.
4. Checkout va order history.
5. Profile update.
6. Wishlist.
7. Search.

## MVP Acceptance Criteria
- Login, cart, checkout, order history, profile, wishlist va search ishlaydi.
- 2s dan kam javob beruvchi asosiy endpointlar.
- Unit va integration testlarning minimal qamrovi:
  - Auth
  - Cart
  - Order
  - Profile
