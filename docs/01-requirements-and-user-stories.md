# 01. Ehtiyojlar va User Stories

## Foydalanuvchi Segmentlari
- Mehmon foydalanuvchi (guest)
- Ro'yxatdan o'tgan xaridor
- Admin/operator

## Asosiy Ehtiyojlar
- Mahsulotni tez topish va filtr qilish.
- Bir necha qadamda savatchaga qo'shish va buyurtma berish.
- Profil, buyurtma tarixi va xohishlar ro'yxatini boshqarish.
- Mobil va desktopda bir xil qulay tajriba.
- Xavfsiz autentifikatsiya va sessiya boshqaruvi.

## User Stories
1. Guest sifatida mahsulotni qidirib, narx bo'yicha saralab ko'rmoqchiman, shunda tez tanlay olaman.
2. Xaridor sifatida 1-2 klikda savatchaga qo'shmoqchiman, shunda checkout tez bo'ladi.
3. Xaridor sifatida profilimda manzil/telefonni yangilamoqchiman, shunda buyurtma osonlashadi.
4. Xaridor sifatida xohlagan mahsulotni wishlist'ga saqlamoqchiman, keyinroq qaytib xarid qilaman.
5. Xaridor sifatida buyurtma tariximni ko'rmoqchiman, shunda holatni kuzataman.
6. Admin sifatida mahsulot qo'shish/o'chirishni tez bajarmoqchiman, katalog doim aktual bo'ladi.
7. Foydalanuvchi sifatida sayt mobil ekranda ham oson boshqarilishini xohlayman.

## Nofunksional Talablar
- P95 sahifa javobi <= 2s.
- Uptime >= 99%.
- WCAG 2.1 AA.
- 3 brauzer (Chrome, Firefox, Edge) va 2 qurilma (desktop + mobile) qo'llab-quvvatlovi.
