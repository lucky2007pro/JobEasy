# 07. Yakuniy Yetkazib Berish Checklist

## Funksional
- [ ] Login, Search, Cart, Checkout, Order, Profile, Wishlist ishlaydi.
- [ ] Mobil va desktop UI da asosiy oqimlar to'liq o'tadi.

## Nofunksional
- [ ] Sahifa yuklanish vaqti <= 2s.
- [ ] Uptime >= 99%.
- [ ] WCAG 2.1 AA talablari bajarilgan.
- [ ] 3 brauzer (Chrome, Firefox, Edge) testdan o'tgan.
- [ ] 2 qurilma (desktop + mobile) testdan o'tgan.

## Sifat
- [ ] Unit testlar yashil.
- [ ] Integration testlar yashil.
- [ ] Xavfsizlik audit report tayyor.
- [ ] Performance test report tayyor.

## DevOps
- [ ] Git repository tartibli.
- [ ] Commit xabarlari aniq formatda.
- [ ] CI/CD pipeline sozlangan.
- [ ] Docker image build va smoke test ishlaydi.
